          //Student Record Management System
Project Description

The Student Record Management System is a Java application that manages student records using Object-Oriented Programming (OOP), File I/O, and Streams. The system allows users to add, search, update, delete, and display student records while storing data in files.

- Features
Add a new student record
Search student by ID
Update student information
Delete student record
Display all students
Generate reports:
Total number of students
Highest GPA
Lowest GPA
Average GPA
Save and load data using file serialization
Student Information

- Each student record contains:

Student ID
Name
Department
GPA
- Topics Used
Java
OOP Concepts
Classes and Objects
Encapsulation
Serialization
Collections (ArrayList)
File I/O
Streams
